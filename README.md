# 常夜桜 -TOKOYO-ZAKURA-

**月の巫女の弾幕を、攻撃せず、ただ避け抜く。**
常夜に舞う桜のもとで紡がれる、耐久型ドット絵弾幕ゲーム（ブラウザ作品・単体HTML5ゲーム）。

```text
プレイ: index.html をHTTPサーバで公開してブラウザで開く
    例) python3 -m http.server 8010  → http://localhost:8010/
    ※ file:// 直開きはフォント読み込みの都合で非推奨(それでも動作はします)
解像度: 480x640 内部レンダリング・整数ピクセル・フルスクリーン自動フィット(レターボックス)
一部機能(フルスクリーン等)は https 環境でのみ有効な場合があります
```

## 遊び方

| 操作 | キー |
|---|---|
| 移動 | 十字キー / WASD（斜め可） |
| 低速移動 | Shift（当たり判定＝中心の光点が見える） |
| 決定 | Z / Enter |
| ポーズ | Esc / P |
| BGM ON/OFF | N　／　効果音 ON/OFF: M　／　フルスクリーン: F |
| タッチ | ドラッグ=移動（相対）・右下「低速」ボタン・左上II=ポーズ |

目的：右上に大きく表示される**残時間**が 0 になるまで、月の巫女「ツクヨミ」の**全8章**の弾幕を生き延びること。自機（折鶴）は攻撃しない。被弾は残機-1＋無敵時間で復帰。残機0で耐久失敗。弾にギリギリ寄せる **GRAZE（かすり）** がスコア源。

## 章（フェーズ）構成 — すべてシナリオ化された弾幕

難易度NORMALの尺。各章は独立した弾幕テーマ・色彩・予備動作を持つ。幕間（インタールード）では全弾が桜花弁へ変換される明確な区切り演出＋次章の予告バナー。

| # | 章 | 弾幕テーマ（発射元/軌道/役割） | 回避設計 |
|---|---|---|---|
| 1 | 月下ノ舞 (30s) | ボス中心の白環(66f間隔/速度1.5)＋狙い3way(46f/2.1)＋月弧花弁(150f,カーブ) | 環の網目を低速で通す基礎訓練。予備動作=御幣発光 |
| 2 | 桜吹雪 (32s) | 2腕螺旋(4f/1.0,8秒毎に反転)＋天からのお札壁(210f,速度0.72)＋狙い苦無(96f/2.4) | 壁の**明示された隙間**(52px×難易度係数)へ誘導 |
| 3 | 式神・狐火 (34s) | 式神からの追尾狐火(96f,旋回0.0165,2.1秒追尾)＋青環礁紋(26f/0.95)＋環(90f) | 追尾は時間で切れる。**誘って切り返す**設計 |

## ボス「月の巫女 ツクヨミ」— 本作の主役

- 46x62ドット絵のパーツアニメーション（後髪2F/体/頭・目開閉/御幣腕2姿）を8形態パレットで生成
- 月光の**光環ハロー**（手続き生成の紙垂飾り環、常時回転）、狐面（2章以降・周遊）、式神紙人形(2F・3/6/7/8章で軌道)
- 章毎に色調が転生：月白→桜→狐火→注連金→散華紅→追月橙→**常夜（黒化・赤眼）**→終焉白金
- 状態機械：顕現(降臨/光環展開)→浮遊(章別ドリフト軌道)→**攻撃予備動作(御幣掲げ+チャージ光)**→転生(白閃+パレット交換+波紋)→消滅(光の柱と花弁昇天)

## 品質保証（実施済みの検証）

本リポジトリの `tools/qa/` に**ゲーム本体をNode.js上で実際に実行する検証ハーネス**を同梱（ブラウザが無い制作環境でも客観検証するため）。ソフトウェアCanvas(2D APIサブセット)＋PNGエンコーダを実装し、実ゲームコードを同一状態で駆動。

- ✅ 全8フェーズ、EASY/NORMAL/HARDで決定的シード完全走行（例外ゼロ、`run`統合テストで警告→8章→クリア→リザルトまで到達確認）
- ✅ 最大同時弾数: EASY 396 / NORMAL 457 / HARD 543（設計上限1200に余裕）
- ✅ 全フェーズの静止画(3時点)+弾幕密度ヒートマップを生成し、**回避ルートの存在と色彩コントラストを目視確認→調整**（例: 4章の壁過密を検出し間引き、3章の密度不足を増補）
- ✅ 敗北ルート(不動プレイヤーで検証)、リトライ導線、ポーズ/ゲームオーバー画面遷移
- ✅ フォントは「ゲームで使う文字のみ」機械抽出してサブセット化(71KB)
- 実行: `cd tools/qa && node run.js [sprites|boss|scenes|phase NORMAL N|sim HARD|run NORMAL]`（Node標準ライブラリのみ・依存不要）

**正直な制約（嘘防止）**：この制作環境にはブラウザが存在しないため、**人間による実機プレイテストは未実施**です。上記は実ゲームコードの決定的自動実行と静止画・密度解析による検証であり、「人が手で遊んでのバランス確認」ではありません。実機での手触り（タッチ感度・音の緊張感・60fps維持）は、プレビューで実際に遊んでのフィードバックを想定しています（推測：現仕様はモダンPC/スマートフォンで60fpsに十分な負荷設計ですが、実測は未検証）。

```

js/ core(基盤) sprites(弾・自機) spr_bg(背景) spr_boss(巫女生成) player bullets
```
